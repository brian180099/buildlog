# BuildLog MVP

## 1. 문서 목적

이 문서는 BuildLog의 첫 번째 버전에서 반드시 만들 기능과 만들지 않을 기능을 정리합니다.

MVP는 사용자가 실제로 써볼 수 있는 가장 작은 첫 버전입니다. BuildLog의 첫 버전은 여러 사용자가 각자의 개발 기록을 관리하고, 공개한 기록을 함께 볼 수 있는 서비스로 만듭니다.

---

## 2. 서비스 소개

BuildLog는 공부한 내용, 프로젝트 할 일, 오류와 해결 방법을 한곳에 기록하는 개발 학습 서비스입니다.

사용자는 자신의 기록을 비공개로 보관하거나 다른 로그인 사용자에게 공개할 수 있습니다. 공개된 공부 기록과 오류 기록에는 댓글과 좋아요를 남길 수 있습니다.

> 공부와 개발 경험을 기록하고, 필요할 때 다시 찾으며, 공개한 경험은 다른 사용자와 나누는 서비스

---

## 3. 해결하려는 문제

- 공부한 내용이 메모장과 AI 대화에 흩어져 다시 찾기 어렵습니다.
- 프로젝트에서 해야 할 일과 끝난 일을 한눈에 확인하기 어렵습니다.
- 이전에 해결한 오류를 다시 처음부터 조사하게 됩니다.
- 유용한 개발 기록을 다른 사람과 나눌 공간이 없습니다.
- 공개 기록에서 부적절한 내용이 발견되어도 알릴 방법이 필요합니다.

---

## 4. 사용자

### 일반 사용자

- 이메일, 비밀번호와 닉네임으로 회원가입하고 로그인합니다.
- 자신의 공부 기록, 할 일과 오류 기록을 관리합니다.
- 기록마다 공개 또는 비공개를 선택합니다.
- 다른 사용자의 공개 기록을 읽습니다.
- 공개 공부 기록과 오류 기록에 댓글과 좋아요를 남깁니다.
- 공개 기록이나 댓글을 신고할 수 있습니다.

### 운영자

- 일반 사용자 기능을 사용할 수 있습니다.
- `.env`에 등록된 운영자 이메일과 일치하는 계정으로 구분합니다.
- 접수된 신고 목록과 신고 내용을 읽을 수 있습니다.
- 첫 버전에서는 신고 처리 상태 변경이나 제재 기능을 제공하지 않습니다.

---

## 5. 첫 번째 버전의 핵심 기능

### 5.1 회원가입과 로그인

- 이메일, 비밀번호와 닉네임으로 회원가입합니다.
- 같은 이메일과 닉네임은 중복 사용할 수 없습니다.
- 로그인 상태는 7일 동안 유지합니다.
- 로그아웃하면 로그인 상태가 즉시 끝납니다.
- 닉네임을 변경할 수 있습니다.
- 계정 삭제, 이메일 확인과 비밀번호 찾기는 만들지 않습니다.

### 5.2 공개와 비공개

- 공부 기록, 할 일과 오류 기록에 공개 여부를 저장합니다.
- 새 기록은 공개 여부를 선택하지 않으면 비공개입니다.
- 비공개 기록은 작성자만 볼 수 있습니다.
- 공개 기록은 로그인한 다른 사용자도 볼 수 있습니다.
- 기록의 수정과 삭제는 작성자만 할 수 있습니다.

### 5.3 공부 기록

- 제목과 내용을 입력해 공부 기록을 만듭니다.
- 내 기록 목록과 상세 내용을 봅니다.
- 제목 또는 내용으로 검색합니다.
- 기록을 수정하거나 삭제합니다.

### 5.4 할 일

- 제목으로 할 일을 만듭니다.
- 새 할 일은 미완료 상태입니다.
- 전체, 남은 일과 완료한 일로 나눠 봅니다.
- 완료와 미완료 상태를 바꿉니다.
- 할 일을 수정하거나 삭제합니다.

### 5.5 오류 기록

- 오류 제목과 오류 내용을 기록합니다.
- 해결 전에는 해결 방법 없이 미해결 상태로 저장할 수 있습니다.
- 해결할 때 해결 방법을 반드시 입력합니다.
- 전체, 미해결과 해결 상태로 나눠 봅니다.
- 제목 또는 오류 내용으로 검색합니다.
- 오류 기록을 수정하거나 삭제합니다.

### 5.6 공개 기록

- 로그인한 사용자는 공개된 공부 기록, 할 일과 오류 기록을 한곳에서 봅니다.
- 기록 종류로 나눠 볼 수 있습니다.
- 공개 공부 기록은 제목과 내용으로 검색합니다.
- 공개 할 일은 제목으로 검색합니다.
- 공개 오류 기록은 오류 제목, 오류 내용과 해결 방법으로 검색합니다.

### 5.7 댓글

- 로그인한 사용자는 공개된 공부 기록과 오류 기록에 댓글을 작성합니다.
- 자신의 댓글을 수정하거나 삭제합니다.
- 기록 작성자는 자신의 기록에 달린 댓글을 삭제할 수 있습니다.
- 공개 할 일에는 댓글을 제공하지 않습니다.
- 댓글 답글은 만들지 않습니다.

### 5.8 좋아요

- 로그인한 사용자는 공개된 공부 기록과 오류 기록에 좋아요를 누르거나 취소합니다.
- 한 사용자는 같은 기록에 좋아요를 한 번만 저장할 수 있습니다.
- 전체 좋아요 수를 보여줍니다.
- 공개 할 일에는 좋아요를 제공하지 않습니다.

### 5.9 신고

- 로그인한 사용자는 공개 기록과 댓글을 신고할 수 있습니다.
- 신고 이유를 작성합니다.
- 한 사용자는 같은 대상을 한 번만 신고할 수 있습니다.
- 신고만으로 기록이나 댓글을 자동 삭제하지 않습니다.
- 운영자만 신고 목록과 신고 내용을 볼 수 있습니다.

---

## 6. 삭제와 연결 데이터 규칙

- 공부 기록이나 오류 기록을 삭제하면 연결된 댓글과 좋아요도 함께 삭제합니다.
- 공개 할 일을 삭제하면 해당 할 일 자체를 삭제합니다.
- 댓글을 삭제하면 해당 댓글은 일반 화면에서 사라집니다.
- 삭제된 기록이나 댓글에 접수된 신고는 운영자 확인을 위해 유지합니다.
- 유지되는 신고에는 신고 당시 대상을 알아볼 수 있는 정보가 남습니다.
- 삭제 전에 사용자에게 확인창을 보여줍니다.

---

## 7. 필요한 화면

- 회원가입 화면
- 로그인 화면
- 내 기록 홈
- 계정 설정과 닉네임 변경 화면
- 내 공부 기록 목록·작성·상세·수정 화면
- 내 할 일 목록·작성·수정 화면
- 내 오류 기록 목록·작성·상세·수정 화면
- 공개 기록 목록과 상세 화면
- 댓글과 좋아요 영역
- 신고 입력 화면
- 운영자 전용 신고 목록과 상세 화면

로그인하지 않은 사용자는 회원가입과 로그인 화면만 사용할 수 있습니다.

## 8. 디자인 방향

- 밝은 배경과 읽기 쉬운 카드 형태를 사용합니다.
- 메뉴, 입력칸과 버튼의 이름을 분명하게 표시합니다.
- 너비 360px 이상의 휴대폰과 컴퓨터 화면을 지원합니다.
- Chrome, Edge와 Safari의 최신 두 버전에서 주요 기능을 확인합니다.

## 9. 첫 번째 버전에서 만들지 않는 기능

- 이메일 확인
- 비밀번호 찾기
- 계정 삭제
- 할 일 마감일
- 할 일 중요도
- 내 할 일 검색
- 댓글 답글
- 신고 처리 상태 변경
- 사용자 제재
- 사진과 파일 첨부
- 이메일 또는 휴대폰 알림
- AI 요약과 자동 분류
- 외부 메모장 또는 AI 대화 가져오기
- 다크 모드

## 10. 기술 구성

- **프론트엔드: React**  
  사용자가 보는 화면과 버튼을 만듭니다.

- **백엔드: FastAPI**  
  회원, 기록, 권한, 댓글, 좋아요와 신고 요청을 처리합니다.

- **운영 데이터베이스: Supabase**  
  실제 서비스 데이터는 Supabase가 제공하는 PostgreSQL에 저장합니다.

- **테스트 데이터베이스: SQLite3**  
  개발 중 자동 테스트와 기능 확인에 사용하며 실제 서비스 데이터는 저장하지 않습니다.

- **비밀 설정**  
  데이터베이스 연결 정보, 로그인 보안 키와 운영자 이메일은 `.env`에서 관리하고 저장소에 올리지 않습니다.

---

## 11. MVP 완료 기준

- 회원가입, 로그인, 7일 로그인 유지와 로그아웃이 동작합니다.
- 사용자는 자신의 닉네임을 변경할 수 있습니다.
- 공부 기록, 할 일과 오류 기록을 작성·조회·수정·삭제할 수 있습니다.
- 각 기록의 공개·비공개와 작성자 권한이 지켜집니다.
- 내 기록의 검색과 상태 필터가 정해진 조건대로 동작합니다.
- 공개 기록 목록, 종류 필터와 검색이 동작합니다.
- 공개 공부·오류 기록에서 댓글과 좋아요가 동작합니다.
- 공개 기록과 댓글을 신고할 수 있습니다.
- `.env`의 운영자 이메일과 일치하는 계정만 신고를 확인할 수 있습니다.
- 기록 삭제 시 댓글·좋아요는 함께 삭제되고 신고는 대상 정보와 함께 유지됩니다.
- SQLite3 자동 테스트를 통과하고 Supabase에서도 주요 저장·조회와 권한 동작을 확인합니다.
- 너비 360px 이상의 화면과 지원 브라우저에서 주요 기능을 사용할 수 있습니다.
