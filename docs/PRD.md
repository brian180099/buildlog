# BuildLog PRD

## 1. 문서 목적

이 문서는 BuildLog 첫 번째 버전의 제작 범위와 완료 조건을 정리한 제품 요구사항 문서입니다.

기능의 세부 입력 조건과 실패 처리 방법은 `docs/spec.md`, 개발 순서는 `docs/plan.md`를 기준으로 합니다.

---

## 2. 서비스 소개

BuildLog는 개발 공부 내용, 프로젝트 할 일, 오류와 해결 방법을 한곳에 기록하는 서비스입니다.

사용자는 자신의 기록을 비공개로 관리하거나 다른 로그인 사용자에게 공개할 수 있습니다. 공개된 공부 기록과 오류 기록에는 댓글과 좋아요를 남길 수 있으며, 공개 기록과 댓글을 신고할 수 있습니다.

---

## 3. 해결하려는 불편

- 공부 내용이 메모장과 AI 대화에 흩어져 다시 찾기 어렵습니다.
- 프로젝트에서 해야 할 일과 완료한 일을 한눈에 보기 어렵습니다.
- 이전에 해결한 오류를 다시 처음부터 조사하게 됩니다.
- 유용한 개발 기록을 다른 사람과 나눌 공간이 필요합니다.
- 공개된 기록이나 댓글에 문제가 있을 때 운영자에게 알릴 방법이 필요합니다.

---

## 4. 사용자와 권한

### 4.1 일반 사용자

- 이메일, 비밀번호와 닉네임으로 회원가입합니다.
- 로그인한 뒤 자신의 기록을 관리합니다.
- 기록을 공개하거나 비공개로 보관합니다.
- 다른 사용자의 공개 기록을 읽습니다.
- 공개 공부 기록과 오류 기록에 댓글과 좋아요를 남깁니다.
- 공개 기록과 댓글을 신고합니다.

### 4.2 운영자

- 일반 사용자 기능을 사용할 수 있습니다.
- `.env`의 운영자 이메일과 계정 이메일이 일치하면 운영자로 구분합니다.
- 운영자만 신고 목록과 신고 내용을 볼 수 있습니다.
- 첫 버전에서는 신고를 확인만 하며 처리 상태 변경, 자동 삭제와 사용자 제재는 하지 않습니다.

### 4.3 로그인하지 않은 사용자

- 회원가입과 로그인 화면만 사용할 수 있습니다.
- 공개 기록을 포함한 기록 화면을 볼 수 없습니다.

---

## 5. 계정 기능

### 5.1 회원가입

사용자가 입력하는 정보:

- 이메일
- 비밀번호
- 닉네임

조건:

- 이메일과 닉네임은 중복 사용할 수 없습니다.
- 비밀번호는 8~64자입니다.
- 닉네임은 2~20자이며 한글, 영문, 숫자와 밑줄만 사용합니다.
- 가입에 성공하면 로그인 화면으로 이동합니다.

### 5.2 로그인과 로그아웃

- 이메일과 비밀번호로 로그인합니다.
- 로그인 상태는 로그인한 날부터 7일 동안 유지합니다.
- 로그아웃하면 로그인 상태가 즉시 끝납니다.
- 7일이 지나면 다시 로그인해야 합니다.

### 5.3 닉네임 변경

- 사용자는 자신의 닉네임만 변경할 수 있습니다.
- 변경한 닉네임은 과거 공개 기록과 댓글에도 표시됩니다.

### 5.4 첫 버전에서 제외하는 계정 기능

- 이메일 확인
- 비밀번호 찾기
- 계정 삭제

---

## 6. 기록 공개 범위

- 공부 기록, 할 일과 오류 기록에 공개 여부를 저장합니다.
- 공개 여부를 선택하지 않으면 비공개가 기본값입니다.
- 비공개 기록은 작성자만 볼 수 있습니다.
- 공개 기록은 로그인한 다른 사용자도 볼 수 있습니다.
- 기록 작성자만 자신의 기록을 수정하거나 삭제할 수 있습니다.
- 공개 기록을 비공개로 바꾸면 기존 댓글과 좋아요는 삭제하지 않고 다른 사용자에게 숨깁니다.
- 다시 공개하면 기존 댓글과 좋아요를 다시 보여줍니다.

---

## 7. 공부 기록

저장하는 정보:

- 제목
- 내용
- 공개 여부
- 작성자
- 작성 날짜와 시간
- 수정 날짜와 시간

사용자가 할 수 있는 일:

- 공부 기록 작성
- 내 공부 기록 목록과 상세 내용 보기
- 제목과 내용으로 내 기록 검색
- 기록 수정과 삭제

조건:

- 제목은 1~100자입니다.
- 내용은 1~5,000자입니다.
- 목록은 최근 작성한 기록부터 보여줍니다.
- 저장·수정에 실패하면 작성 중인 입력값을 유지합니다.

---

## 8. 할 일

저장하는 정보:

- 제목
- 완료 여부
- 완료 날짜와 시간
- 공개 여부
- 작성자
- 작성 날짜와 시간
- 수정 날짜와 시간

사용자가 할 수 있는 일:

- 할 일 작성
- 전체, 남은 일과 완료한 일로 필터
- 완료 또는 미완료 상태 변경
- 할 일 수정과 삭제

조건:

- 제목은 1~100자입니다.
- 새 할 일은 미완료 상태입니다.
- 미완료 항목을 먼저 보여줍니다.
- 같은 상태에서는 최근 작성한 항목을 먼저 보여줍니다.
- 완료하면 완료 시각을 저장하고, 완료를 취소하면 완료 시각을 지웁니다.
- 마감일, 중요도와 내 할 일 검색은 만들지 않습니다.

---

## 9. 오류 기록

저장하는 정보:

- 오류 제목
- 오류 내용
- 해결 방법
- 해결 여부
- 해결 날짜와 시간
- 공개 여부
- 작성자
- 작성 날짜와 시간
- 수정 날짜와 시간

사용자가 할 수 있는 일:

- 미해결 오류 작성
- 전체, 미해결과 해결 상태로 필터
- 오류 제목과 오류 내용으로 내 기록 검색
- 해결 방법 입력과 해결 처리
- 해결 취소
- 오류 기록 수정과 삭제

조건:

- 오류 제목은 1~100자입니다.
- 오류 내용은 1~5,000자입니다.
- 해결 방법은 최대 5,000자입니다.
- 새 오류는 미해결 상태입니다.
- 해결 상태로 바꾸려면 해결 방법이 필요합니다.
- 해결을 취소하면 해결 방법은 유지하고 해결 시각만 지웁니다.

---

## 10. 공개 기록

- 로그인한 사용자는 공개된 공부 기록, 할 일과 오류 기록을 모아 봅니다.
- 공부 기록, 할 일과 오류 기록 종류로 필터할 수 있습니다.
- 공개 기록은 최근 작성한 기록부터 보여줍니다.
- 빈 검색어로 검색하면 전체 공개 기록을 보여줍니다.

종류별 검색 범위:

- 공부 기록: 제목과 내용
- 할 일: 제목
- 오류 기록: 오류 제목, 오류 내용과 해결 방법

---

## 11. 댓글

- 공개된 공부 기록과 오류 기록에만 댓글을 작성할 수 있습니다.
- 댓글은 1~500자입니다.
- 댓글은 오래된 댓글부터 보여줍니다.
- 댓글 작성자는 자신의 댓글을 수정·삭제할 수 있습니다.
- 기록 작성자는 자신의 기록에 달린 댓글을 삭제할 수 있습니다.
- 공개된 할 일에는 댓글을 제공하지 않습니다.
- 댓글 답글은 만들지 않습니다.

---

## 12. 좋아요

- 공개된 공부 기록과 오류 기록에만 좋아요를 누를 수 있습니다.
- 같은 사용자는 같은 기록에 좋아요를 한 번만 저장합니다.
- 다시 누르면 자신의 좋아요를 취소합니다.
- 현재 사용자의 좋아요 여부와 전체 좋아요 수를 보여줍니다.
- 공개된 할 일에는 좋아요를 제공하지 않습니다.

---

## 13. 신고

- 로그인한 사용자는 공개 기록과 댓글을 신고할 수 있습니다.
- 신고 이유는 1~500자입니다.
- 같은 사용자는 같은 대상을 한 번만 신고합니다.
- 신고만으로 기록이나 댓글을 자동 삭제하지 않습니다.
- 일반 사용자는 신고 목록과 신고 내용을 볼 수 없습니다.
- `.env`의 운영자 이메일과 일치하는 계정만 신고 목록과 내용을 볼 수 있습니다.
- 첫 버전에서는 신고 처리 상태 변경, 자동 숨김과 사용자 제재를 제공하지 않습니다.

---

## 14. 삭제와 연결 데이터

- 공부 기록이나 오류 기록을 삭제하면 연결된 댓글과 좋아요도 함께 삭제합니다.
- 공개 할 일을 삭제하면 해당 할 일 자체를 삭제합니다.
- 댓글을 삭제하면 일반 화면에서 즉시 사라집니다.
- 삭제된 기록이나 댓글에 이미 접수된 신고는 운영자 확인을 위해 유지합니다.
- 유지되는 신고에는 신고 당시 대상을 알아볼 수 있는 정보가 남습니다.
- 모든 삭제는 확인창에서 사용자가 동의한 뒤 실행합니다.

---

- 회원가입
- 로그인
- 내 기록 홈
- 계정 설정과 닉네임 변경
- 내 공부 기록 목록·작성·상세·수정
- 내 할 일 목록·작성·수정
- 내 오류 기록 목록·작성·상세·수정
- 공개 기록 목록과 상세
- 댓글과 좋아요 영역
- 신고 입력
- 운영자 전용 신고 목록과 상세

## 16. 화면과 디자인

- 밝은 배경과 읽기 쉬운 카드 형태를 사용합니다.
- 메뉴와 버튼의 이름과 위치를 분명하게 표시합니다.
- 너비 360px 이상의 화면을 지원합니다.
- Chrome, Edge와 Safari의 최신 두 버전에서 주요 기능을 확인합니다.
- 화면 크기가 달라도 로그인 상태와 권한은 동일하게 적용합니다.

- 이메일 확인
- 비밀번호 찾기
- 계정 삭제
- 할 일 마감일
- 할 일 중요도
- 내 할 일 검색
- 댓글 답글
- 신고 처리 상태 변경
- 사용자 제재
- 사진과 파일 첨부
- 이메일 또는 휴대폰 알림
- AI 요약과 자동 분류
- 외부 메모장 또는 AI 대화 가져오기
- 다크 모드

## 18. 기술 구성

- **프론트엔드: React**  
  화면, 입력과 사용자 동작을 담당합니다.

- **백엔드: FastAPI**  
  회원, 기록, 공개 범위, 댓글, 좋아요, 신고와 권한을 처리합니다.

- **운영 데이터베이스: Supabase**  
  실제 서비스 데이터는 Supabase가 제공하는 PostgreSQL에 저장합니다.

- **테스트 데이터베이스: SQLite3**  
  자동 테스트와 기능 확인에 사용하며 실제 서비스 데이터는 저장하지 않습니다.

- **환경 설정**  
  Supabase 연결 정보, 로그인 보안 키와 운영자 이메일은 `.env`에 저장하고 Git에서 제외합니다.

---

## 19. 첫 번째 버전 완료 기준

- 회원가입, 로그인, 7일 로그인 유지, 로그아웃과 닉네임 변경이 동작합니다.
- 공부 기록, 할 일과 오류 기록을 작성·조회·수정·삭제할 수 있습니다.
- 공개·비공개와 작성자 권한이 모든 목록, 검색과 상세 화면에서 지켜집니다.
- 공개 기록의 종류 필터와 검색이 동작합니다.
- 공개 공부·오류 기록에서 댓글과 좋아요가 동작합니다.
- 공개 기록과 댓글을 신고할 수 있습니다.
- 운영자만 신고 목록과 신고 내용을 확인할 수 있습니다.
- 기록 삭제 시 연결된 댓글·좋아요와 신고가 정한 규칙대로 처리됩니다.
- SQLite3 테스트와 Supabase 환경 확인을 모두 통과합니다.
- 지원하는 화면 너비와 브라우저에서 주요 기능을 사용할 수 있습니다.
